1HTML Structure

Lay out every part of the page first, with an id on each element the JavaScript will need later.

  • A <main class="container"> wrapper with an <h1> title and a subtitle.
  • A <form id="search-form"> holding a <select id="field"> (Anything / Title / Author / Subject), a text <input id="query"> and a submit <button id="search-btn">.
  • Hidden <label>s (class visually-hidden) so screen readers still know what each control is.
  • Empty placeholders that JS fills in: #loading, #error, #summary, the #results section and a #more-btn.
<form class="search" id="search-form">
  <select id="field">
    <option value="q">Anything</option>
    <option value="title">Title</option>
    <option value="author">Author</option>
    <option value="subject">Subject</option>
  </select>
  <input id="query" type="text" placeholder="e.g. harry potter" required>
  <button id="search-btn" type="submit">Search</button>
</form>

<div id="loading"><div class="spinner"></div><span>Searching the library…</span></div>
<p id="error"></p>
<p id="summary"></p>
<section id="results" aria-live="polite"></section>
<button id="more-btn" type="button">Load more</button>

The option values (q, title, author, subject) are the exact query parameter names Open Library accepts, so JS can use them directly in the URL.

2CSS Layout & Cards

  • Center a white .container on a warm background using display: flex on body.
  • Make the form a flex row with flex-wrap: wrap so it stacks on small screens.
  • Lay out the results with CSS Grid. auto-fill + minmax() fits as many columns as the width allows, with no media queries needed.
  • Each .book-card is a vertical flex box: cover on top, info below. aspect-ratio: 2 / 3 keeps every cover the same shape and object-fit: cover crops the image instead of stretching it.
  • A small hover lift (transform: translateY(-3px)) gives the cards feedback.
#results {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(180px, 1fr));
    gap: 16px;
}

.book-card { display: flex; flex-direction: column; border-radius: 10px; overflow: hidden; }
.cover     { aspect-ratio: 2 / 3; background-color: #fef3c7; }
.cover img { width: 100%; height: 100%; object-fit: cover; }
.book-meta { margin-top: auto; } /* pushes year/editions to the bottom of every card */

3JS DOM: Wire the Form

Select the elements once at the top of the script, then listen for the form's submit event.

  • Use document.querySelector('#id') for each element and store it in a const.
  • Call e.preventDefault() so the browser does not reload the page when the form is submitted.
  • .trim() the input and show an error if it is empty.
  • Save the query and field, reset page to 1, clear the old cards and call searchBooks().
  • Bonus: a change listener on the select swaps the placeholder text (e.g. "e.g. jane austen" for Author).
form.addEventListener('submit', (e) => {
  e.preventDefault();
  const query = queryInput.value.trim();
  if (!query) {
    showError('Please type something to search for');
    return;
  }
  currentQuery = query;
  currentField = fieldSelect.value;
  page = 1;
  shown = 0;
  resultsEl.innerHTML = '';
  searchBooks();
});

Listening for submit on the form (rather than click on the button) means pressing Enter in the input also works.

4Fetch: Call the API

The endpoint is https://openlibrary.org/search.json. It needs no API key and allows requests from any website.

  • Build the query string with URLSearchParams so spaces and symbols are encoded for you. [currentField]: currentQuery uses the select's value as the parameter name.
  • fields= asks only for the data the cards need, which makes the response much smaller and faster.
  • limit and page control paging (12 books per page).
  • await fetch(...) then await res.json(). The useful parts of the response are numFound (total matches) and docs (the array of books).
  • fetch does not throw on 404/500, so check res.ok and throw your own error.
const params = new URLSearchParams({
  [currentField]: currentQuery,          // e.g. author=jane austen
  fields: 'key,title,author_name,first_publish_year,cover_i,edition_count',
  limit: 12,
  page: page
});
const res = await fetch(`https://openlibrary.org/search.json?${params}`);
if (!res.ok) throw new Error('HTTP ' + res.status);

const data = await res.json();
total = data.numFound;
if (total === 0) throw new Error(`No books match "${currentQuery}"`);
renderBooks(data.docs);

Example of one item in data.docs:

{
  "key": "/works/OL82563W",
  "title": "Harry Potter and the Philosopher's Stone",
  "author_name": ["J. K. Rowling"],
  "first_publish_year": 1997,
  "cover_i": 15155833,
  "edition_count": 400
}

5Render: Display the Cards

Loop over data.docs with forEach and build one card per book using createElement.

  • Cover: if cover_i exists, the image URL is https://covers.openlibrary.org/b/id/{cover_i}-M.jpg (S, M or L for size). Otherwise show a "No cover available" box. Add loading="lazy" so off-screen covers load only when scrolled to.
  • Title & author: set with textContent (not innerHTML) so book data can never inject HTML. author_name can be missing, so fall back to "Unknown author".
  • Meta line: first publish year and edition count.
  • Link: 'https://openlibrary.org' + book.key opens the book's page in a new tab.
  • Append the card to #results, then update the summary ("Showing 12 of 4,069 results…") and show Load more only if shown < total.
function renderBooks(books) {
  books.forEach(book => {
    const card = document.createElement('article');
    card.className = 'book-card';

    const cover = document.createElement('div');
    cover.className = 'cover';
    if (book.cover_i) {
      const img = document.createElement('img');
      img.src = `https://covers.openlibrary.org/b/id/${book.cover_i}-M.jpg`;
      img.alt = 'Cover of ' + book.title;
      img.loading = 'lazy';
      cover.appendChild(img);
    }

    const title = document.createElement('h2');
    title.textContent = book.title;
    // ...author, meta and link built the same way...

    card.append(cover, info);
    resultsEl.appendChild(card);
  });

  shown += books.length;
  moreBtn.style.display = shown < total ? 'block' : 'none';
}

6Bonus: Loading & Errors

Wrap the fetch in try / catch / finally so the user always knows what is happening.

  • Loading: setLoading(true) before the fetch shows the CSS spinner, hides old errors and disables the buttons so the user can't double-submit.
  • Errors: the catch block shows a red message box. A TypeError from fetch means the network failed; other errors are the ones we threw (bad status, no results).
  • finally: runs on success and failure, so the spinner always disappears and the buttons are re-enabled.
  • If "Load more" fails, page is moved back by one so clicking it again retries the same page.
async function searchBooks() {
  setLoading(true);
  try {
    // ...fetch + render (Steps 4 & 5)...
  } catch (err) {
    const message = err instanceof TypeError
      ? 'Could not reach Open Library. Check your connection'
      : err.message;
    showError(message);
    if (page > 1) page--;
  } finally {
    setLoading(false);
  }
}

    border-radius: 50%;
    animation: spin 0.8s linear infinite;
}
